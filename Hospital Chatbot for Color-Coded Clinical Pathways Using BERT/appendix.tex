\chapter{Prototype \texttt{/predict} response fields}

A successful clinical submission returns a JSON object whose fields mirror the mathematics of Chapter~\ref{ch:method}. Table~\ref{tab:api-fields} lists the principal keys.

\begin{table}[H]
\centering
\small
\begin{tabular}{|l|p{9.5cm}|}
\hline
\textbf{Field} & \textbf{Meaning} \\
\hline
\texttt{gate\_score} & Clinical relevance \(g(X)\) in \([0,1]\) \\
\texttt{gate\_passed} & True if \(g(X)\geq 0.30\) \\
\texttt{probabilities} & Softmax vector \(\hat{\mathbf{y}}\) over levels 1--5 \\
\texttt{predicted\_level} & \(\hat{c}=\arg\max_c\hat{y}_c\) \\
\texttt{sats\_colour} & \(C_{\mathrm{NLP}}=f_{\mathrm{SATS}}(\hat{c})\) \\
\texttt{pathway} & Pathway card \(P(C)\): \(T_{\max}\), destination, actions, escalation \\
\texttt{confidence} & Mode probability \(\hat{y}_{\hat{c}}\) for nurse display \\
\hline
\end{tabular}
\caption{Principal \texttt{/predict} response fields and their mathematical counterparts.}
\label{tab:api-fields}
\end{table}

Gate failures omit colour and pathway fields and instead return a prompt requesting a clinical chief complaint.

\chapter{Stage~3 fine-tuning checklist}

For reproducibility, Stage~3 training used the following checklist (full values in Table~\ref{tab:hyperparams}):

\begin{enumerate}
\item Join Triagegeist \texttt{train.csv} and \texttt{chief\_complaints.csv} on \texttt{patient\_id}.
\item Keep only the English free-text chief complaint (why the patient came) and the ESI-style urgency label (\(1\)--\(5\)); drop vitals and demographics.
\item Stratified 90/10 split with seed~42 (\(N_{\mathrm{train}}\approx 72{,}000\), \(N_{\mathrm{eval}}=8{,}000\)).
\item Load BioBERT encoder; discard any prior two-class head; initialise \(W\in\mathbb{R}^{5\times 768}\), \(\mathbf{b}\in\mathbb{R}^{5}\).
\item Train three epochs, batch size 16, learning rate \(2\times 10^{-5}\), weight decay 0.01, max length 128, FP16 enabled.
\item Select the checkpoint with best validation cross-entropy (0.001812 at epoch 3 for the baseline run).
\item Optional stratified-oversampling branch: augment and randomly oversample minority urgent classes on the training split before the same training recipe; compare on external MIMIC/NHAMCS sets (not a Triagegeist holdout headline).
\end{enumerate}
