\section*{Purpose}
This pack states what the project is doing: Part~1 (NLP acuity) is built; Part~2 is protocol-mapped colour pathways; Bayesian fusion is out of scope.

\section{Project map}

\subsection*{One-sentence summary}
A hospital chatbot that maps a patient's chief complaint to a SATS acuity level and colour, then attaches a concrete clinical pathway (destination, time target, actions)---without requiring a TEWS+Bayesian fusion stack at intake.

\subsection*{Architecture (implemented)}
\begin{verbatim}
Chief complaint
  -> Medical gate
  -> OpenMed NER (optional)
  -> BioBERT (5-class acuity)
  -> Softmax -> acuity c-hat in {1..5}
  -> C = f_SATS(c-hat)   % 1 Red, 2 Orange, 3 Yellow, 4/5 Green
  -> Pathway protocol P(C)
\end{verbatim}

\subsection*{Part 2 --- designed}
Colour today is a label; pathways add destination, $T_{\max}$, and actions. TEWS calculator and Bayesian fusion are deferred / out of scope.

\subsection*{Explicit non-goals}
\begin{itemize}
  \item No Bayesian network implementation
  \item No three-layer fusion controller (NLP + TEWS + Bayes)
  \item No claim that BioBERT ``already does Bayesian fusion'' --- it does text$\to$acuity classification; pathways attach deterministically to colour
\end{itemize}

\section{Research gaps}
\begin{enumerate}
  \item \textbf{Acuity discontinuity} --- colour does not drive care after the desk; answer with pathway object $P(C)$.
  \item \textbf{LMIC / Ghanaian chief-complaint NLP} --- local text$\to$SATS colour via BioBERT + Curatio.
  \item \textbf{Green Tag Burden} --- Green pathway diversion to OPD / Minors / Polyclinic.
  \item \textbf{Constrained classifier vs open LLM} --- fixed 5-class head + deterministic maps.
  \item \textbf{Text-only pre-triage} --- NLP acuity before vitals; TEWS nurse-side later.
  \item \textbf{Minority Red safety} --- baseline vs SMOTE; report L1 recall.
  \item \textbf{Colour must mean a pathway} --- not only a badge.
\end{enumerate}

\section{Ten research questions}
\begin{enumerate}
  \item[\textbf{RQ1}] Can unstructured chief complaints map to SATS acuity $1$--$5$ with usable accuracy?
  \item[\textbf{RQ2}] Does correct acuity imply correct colour under fixed $f_{\mathrm{SATS}}$?
  \item[\textbf{RQ3}] How should colours become pathways (destination, $T_{\max}$, actions)?
  \item[\textbf{RQ4}] Can a chatbot deliver pre-triage acuity and pathway guidance?
  \item[\textbf{RQ5}] How well does the system reject non-clinical input?
  \item[\textbf{RQ6}] Does OpenMed NER improve interpretability without replacing acuity?
  \item[\textbf{RQ7}] How does imbalance affect Level-1 (Red) recall?
  \item[\textbf{RQ8}] How overconfident is softmax, and what about nurse oversight?
  \item[\textbf{RQ9}] Can Green diversion be specified to reduce ED congestion?
  \item[\textbf{RQ10}] What LMIC architecture uses NLP acuity without TEWS+Bayes at intake?
\end{enumerate}

Formal Part~1: $\text{Input } X \to \hat{c}\in\{1,\ldots,5\} \to C=f_{\mathrm{SATS}}(\hat{c})$.

Formal Part~2: $C \mapsto P(C)=(T_{\max},\,\mathrm{dest},\,\mathrm{actions},\,\mathrm{escalation})$.
