\section*{Appendix A: ADBAM at a glance}
\begin{algobox}
\textbf{Acheson Demand-Based Allocation Method (ADBAM / DBAM)}
--- find an Initial Basic Feasible Solution for a balanced transportation tableau.

\begin{enumerate}
  \item Choose the destination with the \emph{smallest remaining demand}
        \(a_j^*=\min\{a_j\}\). (Ties: prefer the column whose cheapest available cell is smallest.)
  \item In that column, select the cheapest available cell \(c_{ij}\) (among rows with leftover supply).
  \item Allocate \(x_{ij}=\min\{b_i,a_j\}\). Update supply and demand.
  \item If both supply and demand of that cell are exhausted, return to step~1.
        If only demand is exhausted, stay in the same \emph{row} and pick its next cheapest open column.
        If only supply is exhausted, stay in the same \emph{column} and pick its next cheapest open row.
  \item Repeat until every supply and demand is zero.
\end{enumerate}
Unlike Northwest Corner / Least Cost / Vogel, ADBAM is \emph{demand-led}: it
picks the destination first, then the cheapest route into it.
\end{algobox}
