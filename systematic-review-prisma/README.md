# Systematic review — PRISMA 2020 templates

Renamed from `new-stuff/`. Blank PRISMA 2020 materials for literature reporting in the thesis (Chapter 2).

| File | Purpose |
|------|---------|
| `PRISMA_2020_checklist (1).docx` | Reporting checklist (Title → Discussion). Fill “Location where item is reported” as you write. |
